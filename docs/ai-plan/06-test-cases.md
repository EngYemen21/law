# مصفوفة حالات الاختبار: الواجهة والتدفقات والصلاحيات

هذه مصفوفة عمل داخلية لخطة اختبار مشروع `low-laravel-rectjs`. تتناول حصراً الوظائف والأزرار والفجوات التي رُصدت في تقرير التدقيق، ولا تتطلب تعديل الشفرة.

## بيانات الاختبار المعيارية

| الرمز | الحساب أو الكيان | المواصفات اللازمة |
|---|---|---|
| U-ADM | مدير | صلاحية كاملة، غير موقوف |
| U-EMP-LOW | موظف محدود | بلا صلاحية التذاكر أو القضايا أو التنفيذ، جلسة فعالة |
| U-EMP-CASE | موظف قضايا | لديه «إدارة القضايا والأتعاب» فقط |
| U-LAW | محامٍ معيّن | مسند إليه مورد اختبار واحد فقط |
| U-CLI-A | عميل أ | يملك تذكرة وتنفيذاً وفاتورة اختبار |
| U-CLI-B | عميل ب | يملك بيانات مستقلة ولا تربطه علاقة بالعميل أ |
| EX-01 | طلب تنفيذ | مرحلة مستندات، به مستند مطلوب وآخر مرفوع |
| INV-DUE | فاتورة مستحقة | غير مدفوعة، بلا إثبات تحويل |
| INV-PROOF | فاتورة بانتظار الإثبات | غير مدفوعة، `proof_path` موجود |
| INV-PAID | فاتورة مدفوعة | `paid=true` ومؤشر بوابة دفع صالح |

## معايير نجاح مرحلة الواجهة والصلاحيات

لا تغلق مرحلة الاختبار هذه قبل نجاح جميع حالات **P0**. ويجب فتح تذكرة عيب مستقلة إذا انحرفت نتيجة فعلية عن «النتيجة المقبولة»، موثقةً بمعرف الحالة، الدور، رابط الصفحة، نسخة المتصفح، وقت التنفيذ، لقطة شاشة، وHAR بعد تنقيحه من الرموز والجلسات.
