# مصفوفة حالات الاختبار: التكامل والتزامن والتشغيل

تستكمل هذه المصفوفة اختبارات الواجهة والصلاحيات. يجب تنفيذها في بيئة اختبار معزولة، بمفاتيح تجريبية فقط، وحسابات وهمية، وقاعدة بيانات يمكن إعادة تهيئتها. لا تستخدم بيانات عملاء حقيقية أو مفاتيح إنتاج أو روابط اجتماعات حية.

## نهج اختبار التزامن

تُنفذ حالات **PAY-03** و**PAY-04** على قاعدة اختبار ببيانات معزولة. يجب إرسال الطلبات على حاجز تزامن واحد من عمليتين مستقلتين أو عبر أداة ضغط تسمح بالـconcurrency، لا بالتتابع. بعد كل تشغيل، يفحص المختبر: حالة الفاتورة، معرفات الدفعة، قيود ledger، تاريخ التنفيذ، الإجراءات المنشأة، الإشعارات، وعدد jobs. وتُعاد التجربة عشر مرات على الأقل؛ لأن السباقات لا تظهر دائماً في المحاولة الأولى.

## معايير نجاح مرحلة التكامل والتشغيل

لا يعد أي تدفق ناجحاً إذا اكتفت واجهته بإظهار Toast صحيح بينما سجل الخادم أو قاعدة البيانات يحمل نتيجة مخالفة. وفي اختبارات الدفع والبث، تكون **الحالة الخادمية الموثقة** هي مصدر الحقيقة، وتستخدم سجلات الشبكة وطلبات الاختبار الموقعة كأدلة مساندة فقط بعد تنقيح المعرفات والرموز السرية.
